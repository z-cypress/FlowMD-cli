# Getting Started

## Prerequisites

- **Node.js** >= 18
- **pnpm** (recommended) or npm
- A text editor (VS Code recommended)
- (When using AI blocks) an OpenAI or Anthropic API Key

## Installation

```bash
# Clone the project and install dependencies
git clone <repo-url>
cd FlowMD-cli
pnpm install

# Build
pnpm build

# Global install (optional, convenient for use from any directory)
npm install -g .
```

Verify the installation:

```bash
flowmd --version
```

## Configuring AI

> You can skip this step if you only use data and template blocks.

FlowMD supports two LLM providers: OpenAI and Anthropic. There are two ways to configure:

**Option 1: Environment variable (recommended)**

```bash
export OPENAI_API_KEY="sk-your-api-key"
```

**Option 2: Initialize project configuration**

```bash
flowmd init

# Environment diagnosis
flowmd doctor
```

This creates the `.flow/` directory. Edit `.flow/config.yml`:

```yaml
llm:
  provider: openai          # openai or anthropic
  model: gpt-4o             # model name
  temperature: 0.7          # generation temperature
```

Then fill in your API Key in `.flow/credentials.yml` (see `.flow/credentials.yml.example`).

## Creating Your First Document

```bash
flowmd new hello
```

This creates a `hello.md` file containing a basic template for an AI block. More templates: `flowmd new -- -t data` (data report), `report` (weekly report), `meeting` (meeting minutes), `api` (API documentation), `changelog` (changelog).

````markdown
# hello

## Overview

Describe the purpose of this document.

## AI Analysis

```ai {model: "gpt-4o", output: "summary"}
Analyze the following content and provide insights:
Enter your content here
```

## Summary

{{summary}}

---
*Generated by FlowMD on {{date}}*
````

You can also create files manually. The simplest document only needs an AI block and a variable reference.

## Running the Document

```bash
flowmd run hello.md
```

The console shows execution progress. After execution completes, a new file with a date suffix is generated in the current directory by default (e.g. `hello_2026-07-26.md`).

Other output modes:

```bash
# Output to the terminal
flowmd run hello.md -o stdout

# Inject custom variables
flowmd run hello.md -o stdout --var name=张三 --var project=FlowMD

# Inject variables from a file
flowmd run hello.md -o stdout --var-file vars.yml

# Overwrite the original file
flowmd run hello.md -o inline
```

## Understanding the Execution Flow

The core FlowMD workflow:

1. **Parse** — read the Markdown file and extract the `ai`, `data`, and `template` code blocks
2. **Execute** — run each block sequentially in document order, storing results in the variable context
3. **Render** — replace `{{variables}}` in the document body with their actual values
4. **Output** — write a new file, overwrite the original file, or output to the terminal depending on the output mode

Variables are key: a block's output can be passed to later blocks or the document body via `{{variableName}}`.
